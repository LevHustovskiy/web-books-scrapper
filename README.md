# Парсер каталога книг с выгрузкой в CSV и Excel

Скрипт собирает данные с учебного сайта [books.toscrape.com](https://books.toscrape.com)
(каталог из 1000 книг на 50 страницах) и сохраняет их в два формата:
`books.csv` и `books.xlsx` с оформленной таблицей.

Собираемые поля: **название, цена, рейтинг (1–5), наличие на складе**.

## Пример результата

| Название | Цена, £ | Рейтинг (1-5) | В наличии |
|---|---|---|---|
| A Light in the Attic | 51.77 | 3 | да |
| Tipping the Velvet | 53.74 | 1 | да |
| Soumission | 50.10 | 1 | да |

## Технологии

- Python 3.10+
- `requests` — загрузка страниц
- `BeautifulSoup4` — разбор HTML
- `openpyxl` — генерация Excel с форматированием (ширина колонок, закреплённая шапка)

## Установка и запуск

```bash
pip install -r requirements.txt

python parser.py             # собрать весь каталог (50 страниц)
python parser.py --pages 5   # собрать только первые 5 страниц
```

## Что демонстрирует проект

- работа с пагинацией (обход всех страниц до 404);
- обработка сетевых ошибок и таймауты;
- преобразование «грязных» данных (цена с символом валюты, рейтинг словом в css-классе);
- выгрузка в два формата, кодировка `utf-8-sig` для корректного открытия CSV в Excel;
- вежливый скрейпинг: пауза между запросами, кастомный User-Agent.

> По аналогичной схеме можно собрать парсер под любой публичный сайт:
> маркетплейс, доска объявлений, каталог недвижимости и т.д.
