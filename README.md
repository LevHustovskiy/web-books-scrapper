# Парсер каталога книг с выгрузкой в CSV и Excel

Скрипт собирает данные с учебного сайта [books.toscrape.com](https://books.toscrape.com)
(каталог из 1000 книг на 50 страницах) и сохраняет их в два формата:
`books.csv` и `books.xlsx` с оформленной таблицей.

Собираемые поля: **название, цена, рейтинг (1–5), наличие на складе**.
